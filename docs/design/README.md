## ⚠️ 关键设计约束（跨文件通用）

1. **迁移编号必须递增**（001-013），禁止在已应用迁移上追加（§14.3 #28）。
2. **数据存储是横切关注点**：建表即建索引/PRAGMA，新增表须同步 §5.7.7 关键索引。
3. **每个跨文件引用的章节只在一处有完整内容**，其余放「见 xxx.md §N」指针。
4. **IPC 命令唯一权威在 §8.2**（phase1），其他文件的命令表为摘要，签名以 §8.2 为准。
